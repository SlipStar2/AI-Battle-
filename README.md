# ⚔ AI BATTLE

**Нейросети. Задания. Результаты.**

AI BATTLE — независимый практический эксперимент: разные нейросети получают одинаковые задания, а любой посетитель может открыть результаты и проверить их самостоятельно.

## Первый раунд: BATTLE #001 — Канбан-доска

Семь участников получают один и тот же промт и создают канбан-доску с тремя колонками, карточками, перетаскиванием, редактированием, удалением и сохранением данных.

### Участники
- ChatGPT — OpenAI
- Claude — Anthropic
- DeepSeek — DeepSeek
- Grok — xAI
- Qwen — Alibaba
- Kimi — Moonshot AI
- Алиса — Яндекс

Точные названия моделей и даты тестирования будут внесены после запуска эксперимента.

## Как устроен рейтинг

### Техническая оценка — до 60 баллов

| Критерий | Баллы |
|---|---:|
| Дизайн и удобство | 10 |
| Создание карточек | 10 |
| Редактирование и удаление | 10 |
| Перетаскивание | 10 |
| Сохранение данных | 10 |
| Стабильность | 10 |

### Народный рейтинг

Мнение аудитории собирается отдельно (на первом этапе — через Telegram-опрос). Народное голосование не смешивается с техническими баллами.

## Технологии
- HTML, CSS, JavaScript — без сборщика и серверного фреймворка.
- GitHub — исходный код и история изменений.
- GitHub Pages — бесплатная публикация статического сайта.
- localStorage — локальные данные конкретных демо.

## Локальный запуск

Проект не требует установки зависимостей. Откройте `index.html` в браузере. Для проверки относительных ссылок и поведения удобнее использовать локальный HTTP-сервер или GitHub Pages.

## Публикация через GitHub Pages

Откройте **Settings → Pages** и выберите **GitHub Actions** в разделе Build and deployment. В репозитории подготовлен workflow для публикации сайта. После успешного запуска адрес появится в настройках Pages.

## Принципы честного сравнения
1. Один промт для всех.
2. Новый чат для каждой нейросети.
3. Без дополнительных подсказок.
4. Первая версия сохраняется как есть.
5. Ручные исправления документируются.
6. Все участники проходят один чек-лист.
