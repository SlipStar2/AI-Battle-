# Чек-лист тестирования BATTLE #001

Проверять каждую реализацию в одинаковом браузере и при одинаковом размере окна.

## Функциональность
- [ ] Создать карточку с заголовком и описанием.
- [ ] Отредактировать заголовок и описание.
- [ ] Удалить карточку.
- [ ] Перетащить карточку в другую колонку и обратно.
- [ ] Проверить счётчики.
- [ ] Обновить страницу и проверить сохранение.
- [ ] Закрыть и открыть вкладку, проверить сохранение.
- [ ] Проверить изоляцию данных между демо.
- [ ] Проверить мобильную ширину.
- [ ] Проверить ошибки в консоли.

## Оценка (0–10 по каждому критерию)
- Дизайн и удобство.
- Создание карточек.
- Редактирование и удаление.
- Перетаскивание.
- Сохранение данных.
- Стабильность.
