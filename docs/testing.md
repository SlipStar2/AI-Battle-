# Чек-лист тестирования BATTLE #001

Проверять каждую реализацию в одинаковом браузере и при одинаковом размере окна. Не исправлять код участника перед тестированием.

## Функциональность
- [ ] Открывается ли страница без ошибок?
- [ ] Создать карточку с заголовком и описанием.
- [ ] Отредактировать заголовок и описание.
- [ ] Удалить карточку.
- [ ] Перетащить карточку в другую колонку и обратно.
- [ ] Проверить счётчики.
- [ ] Обновить страницу и проверить сохранение.
- [ ] Закрыть и открыть вкладку, проверить сохранение.
- [ ] Проверить мобильную ширину.
- [ ] Проверить ошибки в консоли.

## Важно о localStorage

Некоторые исходные реализации могут использовать одинаковые ключи localStorage. Чтобы одна работа не влияла на другую, перед проверкой очищайте данные сайта или используйте отдельный профиль/приватное окно. Сам код ради изоляции не меняйте.
