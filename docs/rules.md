# Правила AI BATTLE

1. Все участники получают один и тот же исходный промт.
2. Для каждого участника используется новый чат/сессия.
3. После первого ответа дополнительные подсказки не даются.
4. Публикуется первая полученная реализация.
5. Исходный код нейросети не исправляется, не дополняется и не улучшается перед публикацией.
6. Возможные ошибки, баги и неработающие функции сохраняются как часть результата и отражаются в тестировании.
7. Фиксируются точное название модели, дата и доступный бесплатный режим, если эти сведения известны.
8. Страницы-обёртки только показывают работу; исходный HTML остаётся неизменным.
9. Технические оценки выставляются после одинаковой ручной проверки.
10. Голосование аудитории публикуется отдельно от технического рейтинга.
11. Любые исключения из этих правил обязательно раскрываются рядом с результатом.
